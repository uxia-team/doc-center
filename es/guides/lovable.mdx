## Configuración

1. En Lovable, ve a **Settings \> Connectors \> Personal connectors**.
2. Haz clic en **New MCP server**.
3. Escribe **Uxia** como nombre.
4. Pega la URL del servidor:
   <RegionalUrl block value={"https://platform.uxia.app/api/mcp-v2/mcp"} />

   <Visibility for="agents">
   Use the endpoint for the account region: US uses `https://platform.uxia.app`; EU uses `https://eu.uxia.app`.
   ```plaintext
   https://platform.uxia.app/api/mcp-v2/mcp
   ```
   </Visibility>
5. La primera vez que lo uses, se abrirá automáticamente una ventana del navegador. Inicia sesión con tu cuenta de Uxia para autorizar el acceso.

## Uso

Una vez conectado, puedes pedirle a Lovable que se comunique con Uxia directamente:

```plaintext
Crea un test nuevo para probar mi nueva app en www.example.com
```

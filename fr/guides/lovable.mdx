## Configuration

1. Dans Lovable, accédez à **Settings \> Connectors \> Personal connectors**.
2. Cliquez sur **New MCP server**.
3. Saisissez **Uxia** comme nom.
4. Collez l'URL du serveur :
   <RegionalUrl block value={"https://platform.uxia.app/api/mcp-v2/mcp"} />

   <Visibility for="agents">
   Use the endpoint for the account region: US uses `https://platform.uxia.app`; EU uses `https://eu.uxia.app`.
   ```plaintext
   https://platform.uxia.app/api/mcp-v2/mcp
   ```
   </Visibility>
5. Lors de la première utilisation, une fenêtre de navigateur s'ouvre automatiquement. Connectez-vous avec votre compte Uxia pour autoriser l'accès.

## Utilisation

Une fois la connexion établie, vous pouvez demander à Lovable de communiquer directement avec Uxia :

```plaintext
Crée un nouveau test pour tester ma nouvelle app sur www.example.com
```

L'onglet **Usage** de la page **Organization** vous donne une vue sur l'activité et la consommation de crédits au niveau de l'organisation, pour suivre la capacité et l'adoption. Seuls les propriétaires de l'organisation peuvent l'ouvrir.

## Ce que vous pouvez voir

- **Credit usage this period** : les crédits utilisés et le total pour la période de facturation en cours, ou la confirmation que votre forfait inclut des crédits illimités.
- Les crédits restants pour la période et le pourcentage utilisé.
- **Total tests launched** dans tous les espaces de travail de l'organisation.
- Une répartition **Per-user usage breakdown**.
- Une répartition **Per-workspace usage breakdown**.

## Répartition de l'activité

Les deux tableaux de répartition affichent ces colonnes :

| Colonne | Ce qu'elle compte |
| --- | --- |
| **Total launched** | Tous les tests lancés par cet utilisateur ou dans cet espace de travail |
| **AI User Test** | Les tests lancés, y compris les tests non modérés construits à partir de blocs. La colonne porte encore l'ancien nom. |
| **Accessibility** | Les tests d'accessibilité autonomes créés avant l'arrivée des blocs. Un bloc de vérification de l'accessibilité est compté dans le test auquel il appartient. |
| **Audiences** | Les audiences créées |

Pour en savoir plus sur le fonctionnement des crédits et le contenu de chaque forfait, consultez [Forfaits et crédits](/fr/account/plans-and-credits).

We share detailed security documentation with customers and prospects evaluating Uxia. Some documents require a signed non-disclosure agreement (NDA).

## Available on request

| Document | What it covers | NDA required |
|---|---|---|
| ISO/IEC 27001 audit report | Results of our ISO/IEC 27001:2022 audit by an independent certification body | Yes |
| Data Processing Addendum (DPA) | Processing obligations, technical and organizational measures, subprocessors, retention, and AI training restrictions | No |
| Service Level Agreement (SLA) | Availability target, maintenance windows, support severity levels, and service credits | No |
| System architecture and infrastructure description | Platform architecture, environments, data residency, and security controls | Yes |
| AI data usage and retention statement | How AI model providers are used, retention by Uxia and its providers, and Zero Data Retention | Yes |
| Synthetic test data protocol | How to set up tests so that no real personal data is involved | Yes |
| Incident response for AI agents | How we detect, contain, and communicate incidents involving AI participants | Yes |

We also complete security questionnaires and vendor assessments as part of procurement reviews.

## How to request documents

<Steps>
  <Step title="Email us">
    Write to [hello@uxia.app](mailto:hello@uxia.app) with your company name and the documents you need.
  </Step>
  <Step title="Sign an NDA if needed">
    For documents marked as requiring an NDA, we'll send you our NDA or review yours.
  </Step>
  <Step title="Receive the documents">
    We send the current version of each document to your nominated contact.
  </Step>
</Steps>

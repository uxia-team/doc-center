Uxia's MCP server connects your workspace to Cursor so you can bring test results, transcripts, and UX insights into your coding and design conversations.

## Before you begin

You need:

- A Uxia account. Your workspace's credits and [plan limits](/account/plans-and-credits) apply to anything Cursor creates or launches.
- The latest version of Cursor.
- Access to the Uxia workspace whose data you want to use.

<Steps>
  <Step title="Open Cursor's MCP configuration">
    In Cursor, open **Customize** and add a custom MCP server, or open `~/.cursor/mcp.json` directly.
  </Step>
  <Step title="Add the Uxia server configuration">
    Paste the following JSON configuration:

    ```json
    {
      "mcpServers": {
        "Uxia": {
          "type": "http",
          "url": "https://platform.uxia.app/api/mcp-v2/mcp",
          "headers": {}
        }
      }
    }
    ```

    If you already have MCP servers configured, add the `Uxia` entry inside the existing `mcpServers` object.
  </Step>
  <Step title="Authenticate Uxia">
    Open **Customize** in Cursor, find **Uxia**, and use the toggle to enable it. When Cursor first calls the server, a browser window opens. Sign in to Uxia and click **Authorize**.
  </Step>
  <Step title="Start asking questions">
    Open Cursor Chat and ask Uxia-aware questions, such as:

    - _"List my five most recent Uxia tests."_
    - _"Summarize the insights from the checkout-flow test."_
    - _"What are the biggest usability issues in the latest website test?"_
  </Step>
</Steps>

<Note>
  Uxia connections use the same permissions as your Uxia account. To disconnect, disable or remove the Uxia server in Cursor.
</Note>

## What you can do with Uxia in Cursor

Once connected, Cursor can use your Uxia data as context while you work:

- Create a test for the flow you just built and launch it after you approve the credit cost.
- Review test transcripts and research findings.
- Summarize insights and benchmark scores.
- Turn usability issues into implementation tasks.
- Compare feedback across tests to spot recurring patterns.

## Troubleshooting

If Uxia does not appear as connected in Cursor, confirm the URL is exactly `https://platform.uxia.app/api/mcp-v2/mcp`, save the MCP server configuration, then restart Cursor. If authentication does not open automatically, disable and re-enable the Uxia server from **Customize**.

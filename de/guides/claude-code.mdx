## Claude Code

### Einrichtung

1. Führen Sie den folgenden Befehl in Ihrem Terminal aus, um den Uxia-MCP-Server zu registrieren:
   ```bash
   claude mcp add uxia --scope user --transport http https://platform.uxia.app/api/mcp-v2/mcp
   ```

Starten Sie in Ihrem Terminal eine neue Claude-Code-Sitzung. Wählen Sie in der Liste der MCP-Server **Uxia** aus.

```bash
claude /mcp
```

1. Wählen Sie **Authenticate**.
2. Ein Browserfenster öffnet sich automatisch. Melden Sie sich mit Ihrem Uxia-Konto an, um den Zugriff zu autorisieren.

### Verwendung

Nach der Verbindung können Sie Claude bitten, Aktionen direkt in Uxia auszuführen:

```plaintext
Erstelle einen neuen Test für meine neue App auf www.example.com
```

## Claude Desktop

### Einrichtung

1. Gehen Sie in Claude Desktop zu **Customize \> Connectors**.
2. Klicken Sie auf das Symbol **\+**.
3. Klicken Sie auf **Add custom connector**.
4. Geben Sie **Uxia** als Namen ein.
5. Fügen Sie die Server-URL ein:
   ```plaintext
   https://platform.uxia.app/api/mcp-v2/mcp
   ```
6. Klicken Sie auf **Add**.
7. Bei der ersten Verwendung öffnet sich automatisch ein Browserfenster. Melden Sie sich mit Ihrem Uxia-Konto an, um den Zugriff zu autorisieren.

Wenn Ihr Claude-Workspace einen Team- oder Enterprise-Plan nutzt, müssen Sie unter Umständen die Admins oder Owner Ihres Claude-Workspaces bitten, den Uxia-MCP-Connector für Ihr Team zu aktivieren. Weitere Informationen finden Sie auf [dieser Support-Seite von Claude](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities).

### Verwendung

Nach der Verbindung können Sie Claude bitten, direkt mit Uxia zu kommunizieren:

```plaintext
Erstelle einen neuen Test für meine neue App auf www.example.com
```

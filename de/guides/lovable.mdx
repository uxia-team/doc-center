## Einrichtung

1. Gehen Sie in Lovable zu **Settings \> Connectors \> Personal connectors**.
2. Klicken Sie auf **New MCP server**.
3. Geben Sie **Uxia** als Namen ein.
4. Fügen Sie die Server-URL ein:
   <RegionalUrl block value={"https://platform.uxia.app/api/mcp-v2/mcp"} />

   <Visibility for="agents">
   Use the endpoint for the account region: US uses `https://platform.uxia.app`; EU uses `https://eu.uxia.app`.
   ```plaintext
   https://platform.uxia.app/api/mcp-v2/mcp
   ```
   </Visibility>
5. Bei der ersten Verwendung öffnet sich automatisch ein Browserfenster. Melden Sie sich mit Ihrem Uxia-Konto an, um den Zugriff zu autorisieren.

## Verwendung

Nach der Verbindung können Sie Lovable bitten, direkt mit Uxia zu kommunizieren:

```plaintext
Erstelle einen neuen Test für meine neue App auf www.example.com
```

Uxia lässt sich in die Tools integrieren, die Ihre Produkt-, Design- und Research-Teams bereits nutzen. So kommen Sie von der Erkenntnis zur Umsetzung, ohne Ihren Workflow zu verlassen.

## Verfügbare Integrationen

<CardGroup cols={2}>
  <Card title="Uxia MCP" href="/de/integrations/mcp">
    Erstellen und starten Sie Tests, verwalten Sie Zielgruppen und lesen Sie Ergebnisse aus ChatGPT, Claude, Cursor, Microsoft Copilot und anderen KI-Tools über das Model Context Protocol.
  </Card>

  <Card title="Figma" href="/de/integrations/figma">
    Testen Sie öffentliche Figma-Prototypen mit einer Figma-Prototyp-Aufgabe und melden Sie sich mit Ihrem Figma-Konto an.
  </Card>

  <Card title="Enterprise Auth" href="/de/integrations/enterprise-auth">
    Verbinden Sie Identitätsanbieter für SSO, automatische Nutzerprovisionierung und zentrale Zugriffsverwaltung.
  </Card>

  <Card title="Webhooks" href="/de/integrations/webhooks">
    Erhalten Sie signierte Benachrichtigungen in Ihren eigenen Systemen, wenn ein Test abgeschlossen oder eine Antwort von Teilnehmenden erfasst wird.
  </Card>

  <Card title="Jira" href="/de/integrations/jira">
    Synchronisieren Sie Aufgaben, Issues und Projekt-Updates, damit Ihr Team auf dem Laufenden bleibt.
  </Card>

  <Card title="Notion" href="/de/integrations/notion">
    Bündeln Sie Dokumentation, Projektinformationen und Teamwissen an einem Ort.
  </Card>

  <Card title="Linear" href="/de/integrations/linear">
    Halten Sie Produktplanung, Issue-Tracking und Entwicklungsarbeit im Einklang.
  </Card>

  <Card title="Slack" href="/de/integrations/slack">
    Bringen Sie Benachrichtigungen und Insights von Uxia in die Slack-Channels Ihres Teams.
  </Card>
</CardGroup>

Der Tab **Usage** auf der Seite **Organization** zeigt Ihnen die Aktivität und den Credit-Verbrauch auf Organisationsebene, damit Sie Kapazität und Akzeptanz im Blick behalten. Nur Inhaberinnen und Inhaber der Organisation können ihn öffnen.

## Was Sie sehen

- **Credit usage this period**: verbrauchte Credits und Gesamtkontingent für den aktuellen Abrechnungszeitraum oder die Bestätigung, dass Ihr Plan unbegrenzte Credits enthält.
- Die verbleibenden Credits für den Zeitraum und den verbrauchten Anteil in Prozent.
- **Total tests launched** über alle Workspaces der Organisation hinweg.
- Eine **Per-user usage breakdown**.
- Eine **Per-workspace usage breakdown**.

## Aufschlüsselung der Aktivität

Beide Aufschlüsselungstabellen enthalten diese Spalten:

| Spalte | Was sie zählt |
| --- | --- |
| **Total launched** | Alle Tests, die von dieser Person oder in diesem Workspace gestartet wurden |
| **AI User Test** | Gestartete Tests, einschließlich unmoderierter Tests aus Blöcken. Die Spalte trägt noch den älteren Namen. |
| **Accessibility** | Eigenständige Barrierefreiheitstests, die vor der Einführung der Blöcke erstellt wurden. Ein Block zur Barrierefreiheitsprüfung zählt als Teil des Tests, zu dem er gehört. |
| **Audiences** | Erstellte Zielgruppen |

Mehr dazu, wie Credits funktionieren und was jeder Plan enthält, erfahren Sie unter [Pläne und Credits](/de/account/plans-and-credits).

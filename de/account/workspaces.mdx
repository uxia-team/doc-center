Jeder Workspace in Ihrer **Organization** ist eine abgegrenzte Zentrale für Projekte, Tests, Zielgruppen und Mitglieder. Inhaberinnen und Inhaber der Organisation verwalten Workspaces im Tab **Workspaces** auf der Organisationsseite. In jedem einzelnen Workspace führt Ihr Team Tests durch und arbeitet gemeinsam an der Forschung.

## Die Organisationsseite öffnen

1. Öffnen Sie die linke Seitenleiste.
2. Klicken Sie unten in der Seitenleiste auf Ihr Profil oder Ihren Avatar.
3. Wählen Sie im Menü **Organization Settings**.

<Note>
  Nur Inhaberinnen und Inhaber der Organisation können die Organisationsseite verwenden. Wenn die Seite meldet, dass Sie keinen Zugriff haben, bitten Sie eine Inhaberin oder einen Inhaber Ihrer Organisation, [Sie hochzustufen](/de/account/people) oder die Änderung für Sie vorzunehmen.
</Note>

## Workspaces auf der Organisationsseite verwalten

Im Tab **Workspaces** verwalten Inhaberinnen und Inhaber der Organisation alle Workspaces an einem Ort.

Verfügbare Aktionen:

- Alle Workspaces der Organisation anzeigen.
- Sehen, wie viele Workspaces derzeit im Vergleich zum Limit Ihrer Organisation genutzt werden.
- Mit der Schaltfläche **Create workspace** einen neuen Workspace erstellen.
- Einen bestehenden Workspace umbenennen.
- Sehen, wie viele Mitglieder zu jedem Workspace gehören.

<Warning>
  Wenn Ihre Organisation ihr Workspace-Limit erreicht hat, können keine neuen Workspaces erstellt werden, bis das Limit erhöht wird. [Kontaktieren Sie uns](mailto:hello@uxia.app), um es anzuheben.
</Warning>

<Note>
  Eine Option **Delete** wird angezeigt, Workspaces lassen sich derzeit aber nicht direkt auf dieser Seite löschen. Wenden Sie sich an den Uxia-Support, wenn ein Workspace entfernt werden soll.
</Note>

## Was jeder Workspace enthält

In einem Workspace finden Sie alles, was Sie zum Planen, Durchführen und Analysieren von User Research brauchen:

- **Projects**: Ordner, die zusammengehörige Tests zu einer Initiative, einem Kunden oder einem Produktbereich bündeln. Siehe [Projekte](/de/account/projects).
- **Tests**: alle Tests, die Sie erstellt oder durchgeführt haben. Öffnen Sie einen Test, um seine Ergebnisse, Transkripte und Sitzungen der Teilnehmenden anzusehen.
- **AI Audience**: wiederverwendbare Zielgruppen, die Ihre KI-Teilnehmenden definieren. Erstellen Sie eine Zielgruppe einmal und verwenden Sie sie in jedem künftigen Test. Siehe [Zielgruppen](/de/audiences/overview).
- **Teammitglieder**: Laden Sie Kolleginnen und Kollegen in Ihren Workspace ein, damit sie an Tests mitarbeiten und Ergebnisse ansehen können (im Custom-Plan verfügbar).

## Ergebnisse teilen

Nach Abschluss eines Tests fasst Uxia die Erkenntnisse, Muster und Empfehlungen in den Ergebnissen des Tests zusammen. Sie können sie mit allen teilen, auch mit Stakeholdern ohne Uxia-Konto, und zwar auf zwei Arten:

- **Teilbarer Link**: Erzeugen Sie einen Link nur zum Ansehen und senden Sie ihn direkt an Ihr Team oder Ihre Kunden.
- **Export**: Laden Sie die Ergebnisse herunter, um sie als Datei zu teilen oder in eine Präsentation oder ein Research-Repository aufzunehmen.

Details finden Sie unter [Teilen und exportieren](/de/share-and-export).

Um eine KI-Studie mit echten Menschen fortzusetzen, laden Sie menschliche Teilnehmende zum selben Test ein. Siehe [Testlinks](/de/test-links).

## Teamzugriff und Zusammenarbeit

Im Custom-Plan können Sie Teammitglieder zu Ihrem Workspace hinzufügen und in Echtzeit zusammenarbeiten. Teammitglieder können:

- Testergebnisse ansehen
- Auf geteilte Zielgruppen zugreifen und sie in neuen Tests verwenden
- Tests in der gemeinsamen Workspace-Umgebung starten

Um die Mitgliedschaft auf Workspace-Ebene zu verwalten, nutzen Sie die [Seite People](/de/account/people). Dort laden Sie Personen ein und weisen sie bestimmten Workspaces zu.

<Note>
  Die Anpassung des Workspace, einschließlich gebrandeter Berichte, individueller Workspace-Einstellungen und Teamzusammenarbeit, erfordert den Custom-Plan. [Schreiben Sie an hello@uxia.app](mailto:hello@uxia.app) oder besuchen Sie [uxia.app](https://uxia.app), um mehr über ein Upgrade zu erfahren.
</Note>

## Individueller Workspace (Custom-Plan)

Der Custom-Plan enthält einen vollständig gebrandeten Workspace, der auf Ihre Organisation zugeschnitten ist:

- **Gebrandete Berichte** im Look Ihres Unternehmens, bereit zum Teilen mit Kunden oder internen Stakeholdern
- **Individuelle Workspace-Einstellungen**, abgestimmt auf den Research-Workflow Ihres Teams
- **Priority-Support**, damit Ihr Team schneller vorankommt und Hilfe erhält, wenn es darauf ankommt

Die individuellen Workspace-Einstellungen werden beim Onboarding gemeinsam mit dem Uxia-Team eingerichtet.

## Wann Sie den Support kontaktieren sollten

Nutzen Sie den Link **Contact us** unten auf der Organisationsseite, wenn Sie Hilfe brauchen bei:

- Berechtigungen der Organisation
- Zugriff von Personen
- Einrichtung von Workspaces
- Abrechnung oder Planlimits
- SSO, Provisionierung, Audit-Logs oder Log-Streaming

## Tipps für mehr Ordnung

<Tip>
  Benennen Sie jeden Test nach einem klaren Schema, zum Beispiel mit dem Produktbereich, den verwendeten Blöcken und dem Datum (etwa `Checkout flow – Task + Survey – 2026-10`). So finden Sie frühere Studien leicht wieder, auch wenn Ihr Workspace wächst. Fassen Sie zusammengehörige Tests in einem [Projekt](/de/account/projects) zusammen und verwenden Sie für jedes Segment, jede Persona oder jeden Kunden eigene Zielgruppen. So können Sie sie in mehreren Tests wiederverwenden, ohne die Filter jedes Mal neu anzulegen.
</Tip>

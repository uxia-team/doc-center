Uxia ist darauf ausgelegt, sensible Forschungsmaterialien sorgfältig zu behandeln. Ob Sie Designdateien hochladen, Live-URLs teilen, Aufzeichnungen von menschlichen Teilnehmenden erstellen oder hinter Anmeldeabläufen testen: Alle Daten, die Sie auf die Plattform bringen, werden mit Sicherheit und Datenschutz als Grundprinzip verarbeitet, nicht als nachträglicher Gedanke. Auf dieser Seite erfahren Sie, wie Ihre Daten auf der gesamten Plattform behandelt werden.

## Ihre Design- und URL-Daten

Wenn Sie eine Designdatei hochladen oder eine URL für einen Test angeben, verarbeitet Uxia dieses Material sicher, um die Sitzung jeder teilnehmenden Person durchzuführen.

- **Ihre Daten werden nie zum Trainieren von Modellen verwendet.** Designs, URLs und Testinhalte, die Sie übermitteln, werden nicht dazu verwendet, ein KI-Modell zu verbessern oder feinabzustimmen, weder für Uxia noch für Dritte.
- **Ihre Daten werden nicht mit anderen Nutzerinnen und Nutzern oder Organisationen geteilt.** Jeder Workspace ist abgeschottet. Auf Ihre Testmaterialien haben nur Sie und die Teammitglieder Zugriff, die Sie ausdrücklich einladen.
- **Materialien werden nur so lange wie nötig gespeichert.** Hochgeladene Dateien und URLs werden für die Dauer des Tests aufbewahrt und damit Sie weiterhin auf Ergebnisse und Berichte zugreifen können. Sie werden nicht unbegrenzt über das hinaus aufbewahrt, was zur Erbringung des Dienstes erforderlich ist.

## Aufzeichnungen menschlicher Teilnehmender

Wenn Sie menschliche Teilnehmende über einen [Testlink](/de/test-links) oder ein [menschliches Panel](/de/human-panel) einladen, zeichnet Uxia jede Sitzung auf: den Bildschirm und das Mikrofon der teilnehmenden Person sowie die Gesichtskamera, falls sie diese einschaltet. Diese Aufzeichnungen werden:

- **Sicher gespeichert** auf der Uxia-Plattform und sind nur in Ihrem Workspace zugänglich
- **Vertraulich innerhalb Ihrer Organisation behandelt**: Aufzeichnungen werden nie verkauft oder mit Panel-Partnern geteilt und gelangen nur an die Unterauftragsverarbeiter, die bei der Erbringung des Dienstes helfen, etwa bei der Transkription
- **Zur Durchsicht und Analyse bereitgestellt** im Dashboard Ihres Workspace, zusammen mit den KI-generierten Insights für diesen Test

Aufzeichnungen liefern Ihnen die qualitative Tiefe, die die von der KI zusammengeführten Erkenntnisse ergänzt. Sie bleiben in Ihrem Workspace gespeichert, solange Ihr Konto aktiv ist.

## Zugangsdaten für geschützte und authentifizierte Tests

Wenn das Produkt oder der Bereich, den Sie testen, hinter einem Anmeldebildschirm liegt, können Sie Zugangsdaten angeben, damit KI-Teilnehmende auf geschützte Abläufe zugreifen können. Dabei gilt:

- Zugangsdaten werden bei der Übertragung und im Ruhezustand verschlüsselt und nur entschlüsselt, wenn die Sitzung einer KI-teilnehmenden Person sie benötigt
- Sie sind nie in den Anweisungen an das KI-Modell enthalten. Stattdessen werden sie sicher in die Browsersitzung eingespeist und direkt in die passenden Felder eingegeben, sodass das KI-Modell sie nie sieht
- Passwortfelder bleiben in Transkripten und Screenshots verborgen, andere eingegebene Werte wie ein Benutzername oder eine E-Mail-Adresse können jedoch sichtbar sein
- Sie bleiben auf den Test beschränkt, dem sie hinzugefügt wurden, und sind nur in Ihrem Workspace sichtbar, nie für andere Organisationen
- Sie behalten die Kontrolle über diese Zugangsdaten. Geben Sie keine sensiblen oder potenziell gefährlichen Zugangsdaten ein und ändern Sie sie sofort nach Abschluss des Tests

Verwenden Sie eigens dafür angelegte Testkonten, niemals echte Kunden- oder Admin-Konten. Alle Details finden Sie unter [Zugangsdaten für Teilnehmende](/de/tester-credentials).

Sie können auch eine [interaktive Anmeldesitzung](/de/tester-credentials#interaktive-anmeldesitzung) verwenden. Sie melden sich selbst über die Uxia-Oberfläche an, und wir erfassen die angemeldete Sitzung, sodass wir keine Zugangsdaten speichern. Alle KI-Teilnehmenden des Tests verwenden diese Sitzung. Sie wird eine Stunde nach dem Speichern automatisch gelöscht.

## Während eines Tests verwendete Dateien

Wenn KI-Teilnehmende in Ihrem Ablauf etwas hochladen sollen, etwa einen Lebenslauf, einen Ausweis oder eine Tabelle, können Sie Dateien importieren, die sie dafür verwenden. Dabei gilt:

- Dateien werden bei der Übertragung und im Ruhezustand verschlüsselt und nur abgerufen, wenn die Sitzung einer KI-teilnehmenden Person einen Upload-Schritt erreicht
- Ihr Inhalt wird nie von einem KI-Modell gelesen. Die Datei wird direkt an das Eingabefeld angehängt, sodass nichts daraus in Transkripten, Insights oder Berichten erscheinen kann
- Sie bleiben auf den Test beschränkt, in den sie importiert wurden, und sind nur in Ihrem Workspace sichtbar
- Sie können sie jederzeit entfernen

Wir empfehlen, synthetische statt echter Dokumente hochzuladen. Alle Details finden Sie unter [Dateien für Teilnehmende](/de/tester-files).

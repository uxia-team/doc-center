La pestanya **Usage** de la pàgina **Organization** et dona visibilitat sobre l'activitat i el consum de crèdits de l'organització, perquè puguis controlar-ne la capacitat i l'adopció. Només els propietaris de l'organització la poden obrir.

## Què hi pots veure

- **Credit usage this period**: els crèdits utilitzats i el total del període de facturació actual, o la confirmació que el teu pla té crèdits il·limitats.
- Els crèdits restants del període i el percentatge utilitzat.
- **Total tests launched** a tots els espais de treball de l'organització.
- Un **Per-user usage breakdown**.
- Un **Per-workspace usage breakdown**.

## Desglossament de l'activitat

Totes dues taules de desglossament mostren aquestes columnes:

| Columna | Què compta |
| --- | --- |
| **Total launched** | Tots els tests llançats per aquell usuari o en aquell espai de treball |
| **AI User Test** | Tests llançats, inclosos els tests no moderats creats amb blocs. La columna encara fa servir el nom antic. |
| **Accessibility** | Tests d'accessibilitat independents creats abans que existissin els blocs. Un bloc de revisió d'accessibilitat compta com a part del test al qual pertany. |
| **Audiences** | Audiències creades |

Per saber més sobre com funcionen els crèdits i què inclou cada pla, consulta [Plans i crèdits](/ca/account/plans-and-credits).

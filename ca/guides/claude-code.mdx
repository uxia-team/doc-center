## Claude Code

### Configuració

1. Executa aquesta ordre al terminal per registrar el servidor MCP d'Uxia:
   <RegionalUrl block value={"claude mcp add uxia --scope user --transport http https://platform.uxia.app/api/mcp-v2/mcp"} />

   <Visibility for="agents">
   Use the endpoint for the account region: US uses `https://platform.uxia.app`; EU uses `https://eu.uxia.app`.
   ```bash
   claude mcp add uxia --scope user --transport http https://platform.uxia.app/api/mcp-v2/mcp
   ```
   </Visibility>

Inicia una sessió nova de Claude Code al terminal. A la llista de servidors MCP, selecciona **Uxia**.

```bash
claude /mcp
```

1. Selecciona **Authenticate**.
2. S'obrirà automàticament una finestra del navegador. Inicia sessió amb el teu compte d'Uxia per autoritzar l'accés.

### Ús

Un cop connectat, pots demanar a Claude que faci accions a Uxia directament:

```plaintext
Crea un test nou per provar la meva aplicació nova a www.example.com
```

## Claude Desktop

### Configuració

1. A Claude Desktop, ves a **Customize \> Connectors**.
2. Fes clic a la icona **\+**.
3. Fes clic a **Add custom connector**.
4. Introdueix **Uxia** com a nom.
5. Enganxa la URL del servidor:
   <RegionalUrl block value={"https://platform.uxia.app/api/mcp-v2/mcp"} />

   <Visibility for="agents">
   Use the endpoint for the account region: US uses `https://platform.uxia.app`; EU uses `https://eu.uxia.app`.
   ```plaintext
   https://platform.uxia.app/api/mcp-v2/mcp
   ```
   </Visibility>
6. Fes clic a **Add**.
7. El primer cop que el facis servir, s'obrirà automàticament una finestra del navegador. Inicia sessió amb el teu compte d'Uxia per autoritzar l'accés.

Si el teu espai de treball de Claude té un pla Team o Enterprise, potser hauràs de demanar a l'administrador o al propietari de l'espai de treball de Claude que activi el connector MCP d'Uxia per al teu equip. Trobaràs més informació a [aquesta pàgina d'ajuda de Claude](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities).

### Ús

Un cop connectat, pots demanar a Claude que treballi amb Uxia directament:

```plaintext
Crea un test nou per provar la meva aplicació nova a www.example.com
```

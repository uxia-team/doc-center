---

## Configuració

1. A Lovable, ves a **Settings \> Connectors \> Personal connectors**.
2. Fes clic a **New MCP server**.
3. Introdueix **Uxia** com a nom.
4. Enganxa la URL del servidor:
   ```plaintext
   https://platform.uxia.app/api/mcp-v2/mcp
   ```
5. El primer cop que el facis servir, s'obrirà automàticament una finestra del navegador. Inicia sessió amb el teu compte d'Uxia per autoritzar l'accés.

## Ús

Un cop connectat, pots demanar a Lovable que treballi amb Uxia directament:

```plaintext
Crea un test nou per provar la meva aplicació nova a www.example.com
```

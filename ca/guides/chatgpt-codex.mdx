## ChatGPT

Uxia està disponible directament al [directori de plugins](https://chatgpt.com/plugins) de ChatGPT, aprovat per OpenAI per distribuir-se com a plugin i com a connector MCP. Això vol dir que el pots connectar amb un parell de clics, sense mode de desenvolupador ni haver d'introduir manualment la URL del servidor.

### Configuració

<Steps>
  <Step title="Obre el directori">
    A ChatGPT, ves a **Settings → Apps → Directory**, o obre directament [chatgpt.com/plugins](https://chatgpt.com/plugins), i cerca **Uxia**.
  </Step>
  <Step title="Connecta Uxia">
    Obre la fitxa d'Uxia i fes clic a **Connect**. ChatGPT mostrarà un quadre de diàleg d'autorització.
  </Step>
  <Step title="Autentica't">
    Inicia sessió amb el teu compte d'Uxia per autoritzar la connexió. Un cop aprovada, Uxia queda vinculat al teu compte de ChatGPT amb accés limitat als teus tests, transcripcions i insights.
  </Step>
</Steps>

<Note>
  ChatGPT funciona amb el teu compte d'Uxia actual, així que els crèdits i els [límits del pla](/ca/account/plans-and-credits) del teu espai de treball s'apliquen a tot el que creï o llanci.
</Note>

<Note>
  Si el teu espai de treball de ChatGPT té un pla Business, Enterprise o Edu, és possible que un administrador o propietari hagi d'activar primer l'aplicació d'Uxia per a l'espai de treball. Els membres veuran l'etiqueta **Disabled by admin** fins que s'activi. Els administradors poden activar Uxia des de **Workspace settings → Apps**.
</Note>

### Ús

Un cop connectat, pots demanar a ChatGPT que treballi amb Uxia directament:

```plaintext
Crea un test nou per provar la meva aplicació nova a www.example.com
```

```plaintext
Mostra'm els meus 5 últims tests d'Uxia i resumeix els principals insights de cadascun.
```

## Aplicació Codex

### Configuració

L'aplicació d'escriptori de Codex comparteix les credencials amb ChatGPT. Completa primer la configuració de ChatGPT d'aquesta pàgina i l'aplicació Codex hi tindrà accés automàticament.

### Ús

Un cop connectat, pots demanar a l'aplicació Codex que treballi amb Uxia directament:

```plaintext
Crea un test nou d'Uxia per provar la meva aplicació nova a www.example.com
```

There are three ways to use Figma with Uxia. You can use Figma as a sign-in option, connect your Figma account to import assets into the Uxia canvas, or test a public Figma prototype by pasting its link. The first two use the deeper Figma integration; testing a public prototype does not require a Figma integration or login.

## Use Figma to create your Uxia account

Figma is available as a social login option. When you create an account or sign in to Uxia, you can use your Figma login instead of creating a separate Uxia password.

This is separate from importing Figma assets or testing a Figma prototype. You can use Figma as your login provider without importing anything from Figma.

## Import Figma assets into the Uxia canvas

Use the Figma integration when you want to create a source or flow from a Figma file and then continue building the prototype inside Uxia. Uxia imports the assets from a specific Figma page into the canvas, where you can finish setting up the experience for your test.

To import a Figma page:

<Steps>
  <Step title="Open the user test">
    Create or open the user test where you want to use the Figma assets.
  </Step>
  <Step title="Choose the media source">
    In the **Source** section, select **Media source** and then choose the Figma option.
  </Step>
  <Step title="Connect Figma">
    Sign in to or connect your Figma account when prompted.
  </Step>
  <Step title="Select a file and page">
    Choose the Figma file you want to use, then select the specific page to import.
  </Step>
  <Step title="Import the page">
    Uxia imports all assets from the selected Figma page into the canvas.
  </Step>
  <Step title="Finish the prototype">
    Use the Uxia canvas to arrange the imported assets, define the flow, and complete the prototype before launching the test.
  </Step>
</Steps>

This workflow is useful when you want to adapt the imported design, add interactions, or build the final testable flow in Uxia rather than testing the Figma file exactly as it exists.

## Test a public Figma prototype by link

If you already have a Figma prototype, you do not need to connect Figma or log in with Figma to test it in Uxia.

Create a shareable Figma prototype and set its access so **anyone with the link** can open it. Then:

<Steps>
  <Step title="Open the user test">
    Create or open the user test you want to run.
  </Step>
  <Step title="Choose the Figma prototype source">
    In the **Source** setup, select the **Figma prototype** option.
  </Step>
  <Step title="Paste the prototype link">
    Paste the shareable Figma prototype URL.
  </Step>
  <Step title="Continue setting up the test">
    Finish the remaining test setup and launch the test.
  </Step>
</Steps>

Because the prototype is publicly accessible, both AI and human participants in Uxia can open and use it. No Figma account connection is required for this workflow.

<Note>
  Public-link testing and Figma importing are different workflows. Use a public prototype link when you want participants to test the prototype as it is. Use the Figma integration when you want to import a page's assets and continue building the prototype in the Uxia canvas.
</Note>

## Which workflow should you use?

- **Use Figma sign-in** when you want to create or access your Uxia account with your Figma credentials.
- **Import a Figma page** when you want to bring assets into Uxia and modify or complete the prototype in the canvas.
- **Paste a public prototype link** when you already have a shareable Figma prototype and want AI or human participants to test it without connecting Figma.

## Tips and best practices

- For public-link testing, verify that the prototype opens for someone who is not signed in to Figma before starting the test.
- Use the page import workflow when you need to edit the design, add interactions, or build the test flow in Uxia.
- Select the Figma page that contains the assets you want to use; Uxia imports the assets from that page into the canvas.
- Keep imported pages focused so the canvas is easier to organize and the test flow is easier to review.
- If you import assets into a canvas that already contains a prototype, review the resulting canvas before launching the test.

The Uxia MCP server lets your favorite AI tools talk directly to your Uxia workspace. Once connected, Claude Code, Cursor, Codex, v0, and other [Model Context Protocol](https://modelcontextprotocol.io) clients can work with Uxia in the same chat where you're writing code or iterating on design — no copy-paste, no context switching.

## What you can do

- **Create and launch tests.** Describe what you want to test, and your AI tool sets up the test for you: the task, the follow-up questions and the audience. Launching spends credits, so the assistant previews the cost and asks for your approval before it launches.
- **Manage audiences.** List your audiences, create new ones, and choose the AI participants for a test.
- **Read results and insights.** Pull insights, participant quotes, transcripts, navigation paths, survey answers, benchmark scores, and accessibility findings into your conversation. Check progress and your remaining credits.

Everything happens with your Uxia account, so the same workspace access, credits and [plan limits](/account/plans-and-credits) apply.

## Setup

Connecting Uxia takes three steps: pick the AI tool you want to use, register the Uxia MCP server, and sign in to authorize the connection.

<Steps>
  <Step title="Pick your AI tool">
    Supported clients out of the box:

    | Client | Type | Notes |
    | --- | --- | --- |
    | **Claude Code** | CLI / IDE | Recommended for engineers working in the terminal or VS Code. |
    | **Cursor** | IDE | Native MCP support — pulls Uxia data into Cursor chat. |
    | **Codex** | CLI | For OpenAI Codex CLI workflows. |
    | **v0** | Web | Bring Uxia insights into v0 design generation. |
    | **Other** | Any MCP client | Use the generic HTTP transport for Claude Desktop, custom agents, and other clients. |

    You can also connect non-coding tools like **Claude Desktop** and **ChatGPT**. See the guides for [Claude](/guides/claude-code), [ChatGPT and Codex](/guides/chatgpt-codex), [Cursor](/guides/cursor), [Lovable](/guides/lovable), and [Antigravity](/guides/antigravity).
  </Step>
  <Step title="Register the Uxia MCP server">
    Add the server using the configuration for your chosen tool.

    #### Claude Code

    Run this command in your terminal:

    ```bash
    claude mcp add uxia --scope user --transport http https://platform.uxia.app/api/mcp/mcp
    ```

    #### Cursor

    In Cursor, open **Customize** and add a custom MCP server, or edit `~/.cursor/mcp.json` directly. Add this entry to the `mcpServers` object:

    ```json
    {
      "mcpServers": {
        "Uxia": {
          "type": "http",
          "url": "https://platform.uxia.app/api/mcp/mcp",
          "headers": {}
        }
      }
    }
    ```

    #### Codex

    Run this command in your terminal:

    ```bash
    codex mcp add uxia --url https://platform.uxia.app/api/mcp/mcp
    ```

    #### Other

    Add a new HTTP MCP server and paste the URL below.

    ```text
    https://platform.uxia.app/api/mcp/mcp
    ```
  </Step>
  <Step title="Authenticate">
    The first time your client calls the Uxia MCP server, you'll be redirected to sign in to Uxia and click **Authorize**. After that, your AI tool has scoped access to the tests, audiences and results in your workspace.
  </Step>
  <Step title="Try it out">
    In your AI tool, ask something like:

    - _"List my last 5 Uxia tests."_
    - _"Summarize the insights for the checkout flow test."_
    - _"Create a Uxia test for the sign-up flow at www.example.com with 5 AI participants."_
    - _"What were the top usability issues in my latest live website test?"_

    Your client will call the Uxia MCP server, fetch the relevant data, and answer with real context from your workspace.
  </Step>
</Steps>

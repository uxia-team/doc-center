The **System Usability Scale (SUS)** is a standardized questionnaire used to measure the perceived usability of a digital experience.

After completing a task, Uxia can ask testers the standard SUS questions and combine their responses into a single usability score. This gives you a consistent metric that can be used to compare experiences, track improvements over time, and complement the qualitative insights identified during the test.

## What does SUS measure?

Testers rate the following 10 statements:

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

Each statement is rated on a 5-point scale from Strongly Disagree to Strongly Agree.

The questionnaire intentionally alternates between positively and negatively worded statements. This helps reduce response patterns.

## How Uxia applies SUS

Uxia doesn't simply ask testers for a score. We apply additional techniques when collecting and processing their responses to reduce common LLM's response biases, improve consistency across testers, and increase the accuracy of the final result.

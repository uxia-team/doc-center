Uxia used to have separate test types: **AI User Test**, **AI User Research**, and **Accessibility Test**. They're now **blocks** you combine inside one **unmoderated test** — so a single test can include a task, a survey, a card sort, and an accessibility check, and run with AI participants, human participants, or both.

## Old test types → blocks

| Before | Now |
|---|---|
| AI User Test | [Task block](/task-block) — choose **Live website task**, **Figma prototype task**, or **Media prototype task** |
| AI User Research | [Survey block](/survey-block) |
| Accessibility Test | [Accessibility check block](/accessibility-block) |
| — | [Card sorting block](/card-sorting) (new) |
| AI Moderated Test | [AI-moderated test](/ai-moderated-tests) — a separate test type, coming in October 2026 |

## Where things moved

| Before | Now |
|---|---|
| **Mission** | The **Task** field on a Task block. Same idea, new name. See [Task](/mission). |
| Source step | The task type you pick, plus the **URL** or **Prototype** on the block. Viewport and product status are set when you add the link. See [Live website and Figma links](/source). |
| Post-test questions | Add a **Survey** block after the task. To ask a question only to participants who finished the task, turn on **Only ask testers who complete the flow** on that question. See [Survey block](/survey-block). |
| SUS and UXIA-Q questionnaires | **Benchmarks** toggles on each Task block. See [SUS](/sus) and [UXIA-Q](/uxia-q-score). |
| Advanced settings (credentials and files) | **+ Add credentials** and **+ Add files** on each live website and Figma prototype task. See [Tester credentials](/tester-credentials) and [Tester files](/tester-files). |
| Audience step | **Recruit › AI participants**, where you can mix up to 3 audiences. See [AI participants](/ai-participants). |
| **Launch Test** | **Start recruiting** in Build, then **Launch test** in Recruit. |
| Human Test link (created from a finished AI test) | [Test links](/test-links), created per test in Recruit — no AI test needed first. |
| Test set-up confidence | A [test review](/recruit-participants#test-review) that runs before AI participants start, with **Fix in Build** for anything unclear. |
| Yes / No question | Use a **Multiple choice** question with two options. |
| Accessibility Test wizard | Add an **Accessibility check** block. No audience or participants needed. |

## What's new

- **Several flows in one test.** Add up to 3 Task blocks (1 on the Free plan) — for example, sign-up, search, and checkout — and optionally continue each task from where the previous one left off.
- **Mix research methods.** Combine tasks, surveys, card sorts, and accessibility checks in the same test.
- **Card sorting.** Run open or closed card sorts with AI and human participants.
- **Human participants per test.** Invite your own users with [test links](/test-links) or request a [human panel](/human-panel), alongside AI participants.
- **Ask AI across blocks.** Ask questions about the whole test, or compare blocks. See [Ask AI](/ask-ai).
- **Stop a running test** and get a partial credit refund. See [Analyze results](/analyze-results).

## Your existing tests

- **Tests created before Blocks** are still in your **Tests** list. Most open in the new **Analyze** view; some open their original results in read-only mode.
- **Drafts** you hadn't launched were copied into the new builder, so you can keep editing them as block tests.
- If an older test shows *"This test was launched through an old version of Uxia"*, relaunch it to get the newest results features.
- If you see *"The saved results for this test need help from our team"* or can't find a test's results, [contact us](mailto:hello@uxia.app).

<Tip>
  Looking for the old **Executive Summary**? Open **Chat** in the Analyze sidebar and ask Ask AI to *"Summarize this test"*.
</Tip>

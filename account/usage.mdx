The **Usage** tab on the **Organization** page gives you visibility into organization-level activity and credit consumption so you can keep an eye on capacity and adoption. Only organization owners can open it.

## What you can see

- **Credit usage this period** — credits used and the total for the current billing period, or confirmation that your plan has unlimited credits.
- Remaining credits for the period and the percentage used.
- **Total tests launched** across all organization workspaces.
- A **Per-user usage breakdown**.
- A **Per-workspace usage breakdown**.

## Activity breakdown

Both breakdown tables show these columns:

| Column | What it counts |
| --- | --- |
| **Total launched** | All tests launched by that user or in that workspace |
| **AI User Test** | Launched tests, including unmoderated tests built from blocks. The column still uses the older name. |
| **Accessibility** | Standalone accessibility tests created before blocks. An Accessibility check block counts as part of the test it belongs to. |
| **Audiences** | Audiences created |
